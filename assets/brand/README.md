# Identidad visual de Musubi

El símbolo parte de **び**, última sílaba de 結び. El remate cian representa
los sistemas; las dos marcas representan las APIs (índigo) y la IA (coral).

- `musubi-mark.svg` y `musubi-mark.png`: símbolo con fondo transparente para superficies claras.
- `musubi-mark-dark.svg` y `musubi-mark-dark.png`: versión transparente para fondos oscuros; usa un
  índigo claro para mantener visibles las APIs.
- `favicon.svg` y `favicon-32.png`: iconos compactos con fondo índigo.
- `apple-touch-icon.png`: icono de 180 × 180 px para dispositivos Apple.
- `social-avatar.png`: avatar cuadrado de 512 × 512 px, con margen para recorte circular.
- `social-cover-light.png` y `social-cover-dark.png`: piezas de 1200 × 630 px
  para compartir enlaces o publicaciones. Los SVG correspondientes son sus
  originales editables.

Las piezas finales incluyen el fondo; no lo agregues a los símbolos transparentes.
Al reducir el icono, mantén visibles las dos marcas y no alteres el orden ni el
significado de los colores. Antes de un uso público en una plataforma, comprueba
su recorte y su versión actual de dimensiones recomendadas.
