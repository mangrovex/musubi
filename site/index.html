El nombre

Musubi significa unión. 結び

En japonés, musubi expresa la acción de unir. En este framework, el nombre resume una arquitectura donde tecnologías diferentes no se diluyen: se atan en un punto común y empiezan a trabajar como un sistema.

El símbolo nace de び, la última sílaba de 結び. El remate cian representa los sistemas; las dos marcas, en índigo y coral, representan las APIs y la IA. Tres capacidades que encuentran un lenguaje común.

Inicio rápido

De PyPI a tu primer proyecto.

Instala Musubi con Python 3.11 o superior. El CLI genera un proyecto con Compose, Caddy, Enmasse y un servicio Zato inicial.

python -m pip install musubi-framework==0.2.0
musubi --version
musubi init mi-integracion --profile dev
musubi validate ./mi-integracion
