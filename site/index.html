El nombre

Musubi significa unión. 結び

En japonés, musubi expresa la acción de unir. En este framework, el nombre resume una arquitectura donde tecnologías diferentes no se diluyen: se atan en un punto común y empiezan a trabajar como un sistema.

El logo son tres anillos borromeos: sistemas, APIs e IA. Ningún par está enganchado entre sí, pero los tres juntos no se pueden separar; si quitas uno, los otros se sueltan. Cada anillo conserva su color, y la unión está en cómo se cruzan.

Inicio rápido

Del repositorio a un proyecto en segundos.

El CLI renderiza un proyecto autónomo con Compose, Caddy, Enmasse y un servicio Zato inicial. El runtime no depende del generador.

git clone https://github.com/mangrovex/musubi.git
cd musubi
python -m pip install -e .
musubi init mi-integracion --profile dev
musubi validate ./mi-integracion

Integra sin perder el hilo.
